# Beat Board Prompts

## 剧情概述
- **贪婪众生相**：末日将至，江心月的养父母一家不仅没有危机感，反而因物资和虚假承诺暴露极度贪婪与自私的本性。
- **设局与诱饵**：江心月利用家人的贪婪，在离开前故意向恶毒弟弟透露邻居“富得流油”的假消息，借刀杀人。
- **复仇与反转**：江心月反锁房门将家人困死，闪回揭示邻居实为连环杀手，江心月在电梯中露出复仇成功的冷笑。

## 角色一致性（Character Consistency）
- **江心月（主角）**：女性，20多岁，外表清冷瘦弱，眼神深沉坚毅；身穿一件米色长款风衣，内搭深色高领衫，显得干练且与家庭格格不入；长发低马尾。情绪从隐忍伪装转为残忍冷酷。
- **养父**：50多岁，秃顶，满脸横肉，穿着发黄的白色背心和短裤，肢体语言暴力粗鲁。
- **养母/弟媳/弟弟（江滔）**：群像。家人穿着居家睡衣，色彩俗艳混乱。弟弟江滔20岁出头，染黄发，身形消瘦猥琐，牙齿发黄，眼神充满贪欲。
- **刘大娘（邻居/杀手）**：60多岁，穿着沾满油污的碎花围裙，身形佝偻但结实，面带诡异慈祥的笑容。

## 视觉规范（Visual Guidelines）
- **整体风格**：电影感写实风格（Cinematic Realistic），高对比度，质感粗砺。
- **色彩与光影**：
    - **屋内**：浑浊的暖黄色调（钨丝灯），营造拥挤、燥热、贪婪的油腻感。
    - **屋外/走廊**：阴冷的蓝绿色调（荧光灯），营造惊悚、冷酷、死亡的氛围。
    - **光质**：多用顶光和侧逆光，强调面部阴影和眼神的恶意。
- **镜头语言**：多使用特写捕捉微表情，利用门框、走廊制造封闭构图（Frame within Frame），荷兰角（Dutch Angle）暗示不安。

## 九宫格布局
- **第1行（贪婪）**：物资曝光 -> 养父暴怒 -> 虚假安抚
- **第2行（离别与设局）**：孤身离开 -> 恶魔低语 -> 杀意萌生
- **第3行（处决）**：关门落锁 -> 惊悚真相 -> 电梯冷笑

## Panel Breakdown（九格关键帧拆解）

1（第1行左）——【物资狂欢】
视角：全景，俯拍。储物间的门大开，露出堆积如山的米面粮油和罐头。养母和弟媳如同饿狼扑食般趴在物资堆上，贪婪地往怀里塞东西，面目因兴奋而狰狞扭曲。侧光打亮她们夸张的肢体，背景是杂乱阴暗的公寓客厅，空气中漂浮着尘埃。
重点：堆积的物资与人物贪婪姿态的强烈对比。

2（第1行中）——【暴怒一家之主】
视角：中景，低角度仰拍（Low Angle）。养父处于画面中心，暴怒地一脚踢翻身边的纸箱，杂物飞溅。他手指指着画外的江心月怒骂，唾沫横飞，脸上青筋暴起，穿着脏兮兮的背心。背景阴影中，弟弟江滔抱臂站立，一脸不耐烦和不满。
重点：暴力的肢体语言和压抑的家庭氛围。

3（第1行右）——【虚假的承诺】
视角：近景，过肩镜头。江心月（背影）手搭在弟弟江滔肩上，侧脸带着虚假而僵硬的讨好笑容。对面养父正贪婪地抚摸着一台崭新的冰柜，眼神发亮。屋内昏黄的灯光照在江心月脸上，半明半暗，暗示她的伪装。
重点：江心月皮笑肉不笑的表情与家人的贪婪神态。

4（第2行左）——【冷暖两重天】
视角：建立镜头，深焦（Deep Focus）。前景是玄关，江心月身穿米色风衣，孤身一人拉着行李箱杆，背影决绝冷漠。背景深处，客厅里全家人正在疯狂翻箱倒柜搜刮财物，无人回头看她一眼。
重点：前景冷色调与背景暖色调的色温对比，强化主角的孤独与决绝。

5（第2行中）——【恶魔的低语】
视角：特写，双人构图。公寓门口幽暗的走廊，江心月凑近江滔耳边，用手遮嘴压低声音，眼神神秘地指向画外（隔壁）。江滔侧耳倾听，表情从不耐烦转为贪婪的专注。走廊感应灯惨白的光线投下浓重的阴影，氛围诡秘。
重点：江心月设局时的神秘感与弟弟上钩的瞬间。

6（第2行右）——【猎手的注视】
视角：极端特写（Extreme Close-up）。江滔的面部占据画面。他死死盯着隔壁紧闭的防盗门，眼球凸出，舌头贪婪地舔过干裂的嘴唇，露出一口黄牙。眼神中流露出毫不掩饰的恶意与杀意。极端的顶光让他的眼窝深陷，如鬼魅般恐怖。
重点：赤裸裸的贪婪与杀意，人物丑态毕露。

7（第3行左）——【棺材落锁】
视角：主观视角（POV）。从门外的视角看去，厚重的防盗门正在重重关上，只剩一条缝隙。缝隙中露出江心月半张冰冷的脸，她冷冷地注视着门内被困的家人们，仿佛在看一口棺材。门上的铁栏杆形成牢笼般的视觉隐喻。
重点：门缝中的冷眼与“关门”这一象征性动作。

8（第3行中）——【真相：屠夫邻居】
视角：闪回画面，风格突变。阴森的楼道，邻居刘大娘站在阴影里，脸上挂着慈祥却诡异的笑容。手里提着一把还在滴血的剔骨刀，刀尖血迹清晰可见。身后半敞的房门内，隐约可见倒吊的尸体轮廓。色调是病态的暗红与黑。
重点：巨大的惊悚反转，滴血的刀与尸体暗示。

9（第3行右）——【复仇的冷笑】
视角：正面试图，特写。电梯内，金属门即将闭合。光滑的金属表面映出江心月的倒影，她嘴角上扬，露出一抹残忍而释然的冷笑。电梯内的冷白光与周围的黑暗形成强烈反差。
重点：主角复仇完成后的快感与黑暗面的彻底释放。

- **画幅比例**：16:9
- **一致性**：确保江心月的风衣造型在第4、5、7、9格完全一致；确保家庭环境的杂乱与光线氛围前后统一。
- **细节**：重点刻画人物眼神的光点（Eye Light），增强惊悚感。
