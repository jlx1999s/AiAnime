# 节拍拆解表

## 基本信息
- 项目名称：最后的晚餐
- 集数/章节：第2集
- 素材来源：剧本
- 视觉风格：真人写实 / 悬疑惊悚
- 目标媒介：短剧
- 画幅比例：16:9（横屏）

## 节拍拆解

| Beat | 事件摘要 | 观众获得 | 强度 | 锚点 |
|------|---------|---------|------|------|
| 1 | 储物间门打开，露出满屋物资，养母和弟媳贪婪地扑向食物。 | 视觉冲击（物资丰富）与角色贪婪本性的确立。 | 高 | 是 |
| 2 | 养父因未买新车而暴怒，踢翻纸箱指责江心月败家。 | 冲突爆发，展示家庭内部极度自私的权力结构。 | 中 | 是 |
| 3 | 江心月用虚假的豪车承诺安抚弟弟和养父，平息怒火。 | 主角的伪装与操控能力，暂时缓解冲突。 | 低 | 是 |
| 4 | 江心月拖着行李箱准备离开，全家人忙着搜刮财物，无人理会。 | 强烈的冷暖对比，强化主角的孤独与家庭的冷漠。 | 中 | 是 |
| 5 | 江心月故意凑近弟弟江滔，谎称邻居刘大娘家富得流油。 | 剧情关键转折，主角设下陷阱（诱饵）。 | 中 | 是 |
| 6 | 江滔听信谎言，看向隔壁房门，眼中流露出毫不掩饰的恶意。 | 悬念建立，弟弟上钩，预示即将发生的罪恶。 | 高 | 是 |
| 7 | 江心月走出大门，反锁房门，将家人关在"棺材"里。 | 象征性动作，切断退路，复仇计划正式启动。 | 中 | 是 |
| 8 | 闪回画面：上一世刘大娘手持滴血剔骨刀，屋内挂着尸体。 | 惊悚揭秘，反转剧情，揭示"猎物"其实是"猎手"。 | 高 | 是 |
| 9 | 电梯门关闭，江心月露出残忍冷笑，伴随磨刀声收尾。 | 情绪高潮，复仇的快感与黑暗的结局暗示。 | 高 | 是 |
