# 剧情拆解

**小说类型**：重生/古言

## 剧情列表

### 第1批（第1-6章）

【剧情1】皇帝寝殿，庾晚音对暴君夏侯澹使出浑身解数献媚，却被冷漠拒绝"滚吧"，情绪钩子：反差打脸，第1集，状态：已用

【剧情2】皇帝寝殿，庾晚音壮胆挑开床幔，发现暴君竟是穿越来的总裁，两人用英语确认身份，情绪钩子：身份反转，第1集，状态：已用

【剧情3】皇帝寝殿，庾晚音与夏侯澹达成狼狈为奸的战略合作，约定联手对抗天选之子端王和炮灰女，情绪钩子：结盟同盟，第1集，状态：已用

【剧情4】后宫宫宴，谢永儿献宝式拿出吉他弹奏《卡农》炫才艺，自以为惊艳四座实则暴露穿书者身份，情绪钩子：打脸现形，第1集，状态：已用

【剧情5】后宫宫宴，夏侯澹与庾晚音眼神交流确认"炮灰女也是穿的"，端王夏侯泊在场观察一切，情绪钩子：三方博弈，第1集，状态：已用

【剧情6】庾晚音偏殿，庾晚音向谢永儿抛出橄榄枝试图"姐妹和解"，谢永儿表面应承内心只想除掉她，情绪钩子：虚与委蛇，第2集，状态：已用

【剧情7】御花园，小太监碰瓷诬陷庾晚音与侍卫私通，裙摆被洒魏紫花汁作为物证，情绪钩子：陷害危机，第2集，状态：已用

【剧情8】御花园，夏侯澹看穿拙劣宫斗计谋直接将两个证人拖走，庾晚音用眼神制止他OOC，情绪钩子：反套路破局，第2集，状态：已用

【剧情9】皇帝寝殿，庾晚音与夏侯澹吃火锅商讨对策，决定策反端王谋士胥尧，并计划伪造证据陷害端王，情绪钩子：阴谋布局，第2集，状态：已用

【剧情10】御书房，夏侯澹召见胥尧入宫，一番话暗示端王才是当年陷害他父亲的幕后黑手，胥尧震惊失态，情绪钩子：离间计策，第3集，状态：未用

【剧情11】朝堂之上，夏侯澹当众发疯提剑追杀户部尚书，侍卫手起刀落当场斩杀，原因是"他笑得太大声"，情绪钩子：暴君上线，第3集，状态：未用

【剧情12】朝堂之上，夏侯澹将球踢给端王处理军饷纠纷，端王被迫表态，洛将军对端王心生不满，情绪钩子：挑拨离间，第3集，状态：未用

【剧情13】藏书阁二楼，端王与胥尧"偶遇"庾晚音，庾晚音强撑白莲花人设应对，端王指出她前后变化并索要"王八图"作为回礼，情绪钩子：暗中试探，第4集，状态：未用

【剧情14】慈宁宫后宫妃嫔请安，魏贵妃当众刁难庾晚音并讽刺她是"以色事人"，庾晚音被迫下跪，情绪钩子：职场霸凌，第4集，状态：未用

【剧情15】慈宁宫，夏侯澹突然驾到，三言两语将贺嫔拖出去活埋，庄妃被打入冷宫，庾晚音于心不忍用眼神制止，情绪钩子：杀鸡儆猴，第4集，状态：未用

【剧情16】慈宁宫，太后牵着小太子登场兴师问罪，指责夏侯澹专宠庾惑乱后宫，庾晚音跪地求情被太后记恨，情绪钩子：婆媳对立，第4集，状态：未用
